CRYPTO RECA DASHBOARD v0.2 PWA

ARCHIVOS PARA GITHUB
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- carpeta icons/

IMPORTANTE
Sube el contenido de esta carpeta al repositorio de GitHub, NO el ZIP.

PARA INSTALAR EN ANDROID
1. Publica el repositorio mediante GitHub Pages (HTTPS).
2. Abre la URL publicada en Chrome/Android.
3. Pulsa "Instalar app" si aparece en el dashboard; si no, menú de Chrome > Añadir a pantalla de inicio / Instalar aplicación.
4. Se creará un icono "Crypto Reca" y se abrirá como app independiente.

DATOS
- Se guardan localmente en el navegador/dispositivo.
- Puedes exportar e importar un backup JSON desde el propio dashboard.
- Esta versión no sincroniza automáticamente móvil y portátil.
